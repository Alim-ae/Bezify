# Contributing

Thanks for your interest in Bezify.

## Bug reports and ideas

Please open an **Issue**. For bugs, include:
- your After Effects version and operating system
- what you selected (layer type, keyframes) and what you clicked
- what you expected and what happened
- a screenshot if the panel looks wrong

## Code contributions

I am **not accepting pull requests at the moment**. Bezify's author wants to keep the freedom to release future versions under a different license, and that is only possible while all of the code is owned by one person. If this changes, this file will be updated with a contributor agreement.

You are of course free to fork the project under the GPL-3.0 license. If you publish a fork, please use a different name and logo.
